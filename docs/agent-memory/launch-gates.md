# Human launch gates

The private preview may contain fixtures, licensed test media, and clearly labelled editorial examples. Do not treat it as a public publication.

| Gate | Why a person must decide | Current state |
| --- | --- | --- |
| Editorial approval | A person must verify every factual claim and perspective framing before public release. | Pending |
| Source and media rights | A person must accept the licence record and visible credit for each asset. | Pending |
| Community safety policy | Comments, public submissions, polls, and moderation need policy, staffing, and escalation rules. | Pending |
| Notifications | Real emails or push messages need consent, provider setup, and an approved send policy. | Pending |
| Google sign-in | OAuth credentials and consent-screen details must be created in the owner’s Google Cloud account. | Pending |
| Deployment visibility | The Vercel preview must be reviewed before any public promotion or DNS change. | Pending |
