# Syāt agent memory

This folder is the short, human-readable record that lets future work continue without guessing.

- `product-decisions.md` records settled product choices.
- `launch-gates.md` records work that needs a human sign-off before public release.
- `integration-state.md` records connected services without secrets.
- `build-ledger.md` records build slices, evidence, and important rulings.

Do not put passwords, API keys, connection codes, private tokens, or personal data in this folder.
