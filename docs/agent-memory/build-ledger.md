# Build ledger

## 2026-08-31

- Ruling: use a private Vercel preview, static local media derivatives, Vercel Hobby, and Convex free plan. This is the smallest coherent route within the authorized budget. If traffic or assets outgrow it, a human must approve a storage and hosting change.
- Ruling: seed structural editorial fixtures first, then ingest only sources whose rights and terms can be recorded. This protects the product from presenting unsourced generated text as news.
- Ruling: Warm Commons is the private-preview default. It carries the supplied prototype's vivid marigold and aubergine contrast into a readable rounded system; A and C remain tested variants, not unrelated mock-ups. If this direction proves too decorative during reading tests, switch the default token set without changing the content contract.
- Ruling: Convex development runs in Europe (Ireland). This is the closest offered region for the intended Indian audience; server-rendered Vercel pages reduce the practical effect for public reading.
- Ruling: RSS feeds are intake metadata, not story copy. The 100-item private queue remains link-only and needs editorial review, so the preview never implies publisher headlines are Syāt reporting.
- Ruling: describe the queue as India-first source selection rather than claiming every linked event occurs in India. Any model job must name its India connection in the input, so the editor can assess relevance rather than infer it from a headline.
- Ruling: take turns across feeds when filling the fixed 100-item queue. A faster section cannot crowd out specialist or national feeds merely because it posted more frequently that morning.
- Ruling: source-bound model drafts now require traceable content blocks. The parser can prove a paragraph points to known IDs; only an editor can prove that the underlying source really supports the sentence.
- Ruling: every parsed model draft receives an automatic review record before Studio. It blocks direct quotes not found in the supplied excerpt and duplicate claims; it only warns about, and never decides, publisher diversity, media rights, dates, and India connection. A human remains the only publication decision-maker.
- Ruling: DeepSeek V4 Flash was initially spending completion tokens on hidden reasoning and truncating the large strict response. The client now requests `reasoning.effort: "none"`, has a 3,200-token response cap, and times out at 75 seconds. A live fictional smoke job completed in about 12 seconds with an estimated five-paise cost and stayed review-only.
- Ruling: introduce the first-use guide through a quiet two-minute link on Home instead of intercepting the first reading action. The guide makes account and human-review gates visible before a visitor looks for unfinished features.
- Ruling: Better Auth is fixed at 1.6.22, the first non-vulnerable release compatible with the installed Convex component's `<1.7.0` peer range. The component's generic type does not model the passkey client plugin, so a documented boundary cast is kept only in the provider wrapper. Runtime code still builds and Convex functions compile.
- Ruling: the Vercel project uses the Next.js preset on Node 24 and Vercel Authentication for private review. Vercel's first successful deployment necessarily targeted production, so it is retained only as a protected, unaliased staging build; the working review deployment is a protected preview. A normal unauthenticated request redirects to Vercel sign-in, and the removed default alias returns 404.
- Ruling: pin the app runtime to Node 24.x, the Vercel runtime already used for the successful preview builds. This avoids an unplanned major-version upgrade from an open-ended engine range.
- Ruling: `CONVEX_SITE_URL`, `NEXT_PUBLIC_CONVEX_URL`, and `NEXT_PUBLIC_CONVEX_SITE_URL` must be configured in the matching Vercel environments. The first build failure made this explicit; the documented environment template now includes all three without exposing any values.
- Ruling: remove the unused legacy `@convex-dev/auth` package. It pulled an abandoned Lucia-based dependency stack into builds without being imported. The active Better Auth / Convex integration remains the only auth implementation and the production dependency audit is clean.
