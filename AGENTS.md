# Syāt working notes

## How to work here

- Use plain words in product copy and contributor notes.
- Never expose `.env.local` values or paste keys into source files.
- Keep `docs/agent-memory/` current when a product decision, external dependency, or launch gate changes.
- Build public reading pages as static server-rendered pages first. Add client code only when people need an interaction.
- Every media item needs a source, rights basis, creator credit, and review status before it can be published.
- The public product is called **Syāt**. “Reframe” is a quieter feature label, not the home-page headline.

## Product guardrails

- Design for a calm, rounded, welcoming reading experience; use serif and sans-serif typography together with restraint.
- Avoid stock AI-looking gradients, fake metrics, generic hero art, and visual noise.
- Never imitate Googlebot or bypass a publisher’s stated access rules.
- Keep Vercel Hobby and Convex free plan limits in mind. The current paid AI budget target is at most ₹1,400/month, with the wider monthly ceiling held below ₹2,000 while private preview is active.
- A human must approve real publication, source/rights decisions, public community features, notifications, and any external launch.
